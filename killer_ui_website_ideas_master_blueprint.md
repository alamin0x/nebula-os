# BEFORE STARTING ANY PROJECT ⚡

## Golden Rule
A beautiful website is NOT:
- 500 animations
- heavy effects everywhere
- random particles
- giant libraries

A beautiful website IS:
- smooth
- responsive
- polished
- clean motion
- good spacing
- consistent design
- optimized rendering

---

# PERFORMANCE RULES (VERY IMPORTANT) 🧠

## 1. Use These Technologies

### Frontend
- React + Vite
- TailwindCSS
- Framer Motion
- GSAP (only where necessary)

### Optional
- Three.js (only for hero sections/backgrounds)
- Zustand (lightweight state management)
- Lenis (smooth scrolling)

---

## 2. Avoid Lag

### NEVER:
❌ animate everything
❌ use 10 shadows per element
❌ huge background videos
❌ too many particles
❌ 4K images
❌ heavy blur everywhere
❌ 100 React re-renders

### DO:
✅ lazy loading
✅ optimized images (webp)
✅ GPU animations
✅ transform/opacity animation only
✅ memoization
✅ code splitting
✅ reduce DOM elements

# PERFORMANCE MASTERCLASS ⚡

# 1. Animation Optimization

## GOOD
```css
transform: translateY()
opacity
```

## BAD
```css
top
left
width
height
```

---

# 2. Image Optimization

Always:
- webp
- lazy loading
- responsive images

---

# 3. Rendering Optimization

## Use:
```js
React.memo()
```

For expensive components.

---

# 4. Split Code

Use:
```js
lazy()
Suspense
```

---

# 5. Avoid Massive Libraries

Instead of:
- giant UI kits

Use:
- Tailwind
- small libraries

---

# 6. Reduce Re-renders

State mistakes destroy FPS.

- Zustand
